# Contributing to AMVO

Contributions should improve public-source intake, bounded checks, proof-audit methods, security, tests or documentation.

Use primary public citations with pinned versions where possible. Keep authorship and checker credits separate. Do not copy private or unlicensed sources. Explain assumptions, known objections, failed tests and the scope of any result. Run tests, source validation and the publication gate. Disclose material reviewer conflicts and AI assistance.

The simplest submission is a metadata-only source record, review.status=unreviewed. Independent mathematical certification requires further evidence and is **not** a feature of v0.1.
